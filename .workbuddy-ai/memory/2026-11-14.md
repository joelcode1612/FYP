Gotchas hit:
- A `@client` component may only take **primitive** parameters — passing a
  `Future<PropertyEvidence>` into `LocationInsightsV4` failed the jaspr build
  ("@client components only support parameters of p…"). It loads its own copy.
- Jaspr `path(...)` requires the children positional: `path(attributes: {...}, [])`.
- Do NOT name a state field and a method the same (`_infoTab`) — the call site
  resolves to the field and fails with `invocation_of_non_function_expression`.
- Tab 3 is mounted only when selected: `property_leaflet_map.js` calls
  `invalidateSize()` on init but has no ResizeObserver, so a map created inside
  a hidden panel stays 0×0. Cost: the radius/category choice resets per visit.

Headless verification blocked: the page needs a signed-in session, and
`tool/session_harness.js` swaps the auth bridge so Playwright route stubs never
see `/api/**`. Verified by analyze + build + bundle-string checks instead.
