  compiled OUT unless `hooks.user_defines.dartcv4.include_modules` reaches the build hook

  sibling). Fixed nesting in `fyp_mobile_app/pubspec.yaml` — but symbols were STILL absent
  because…

  pubspec** (`FYP/pubspec.yaml`). Member-level defines never reach the hook. After adding the
  block to the root, the hook log confirms `[dartcv4] merged modules: {imgproc, imgcodecs,
  stitching, features2d, flann, calib3d}`.
- Reference app worked because it is a standalone app (its pubspec IS the root).
- Version parity: both projects resolve opencv_dart/dartcv4 2.2.2 + meta 1.18.0 on Flutter
  3.44.6 — no version conflict; `flutter_test`/meta is fine at dartcv4 2.2.2.
