# Project1 — Jaspr Geographic / Report Demonstrator

**STATUS:** Source scaffold created and static JS syntax checked. **NOT BUILT / NOT INTEGRATED / NOT TESTED IN DART / NOT AUTHORISED FOR PRODUCTION.**

This is a **standalone, synthetic-only** Jaspr UI candidate with OpenStreetMap basemap rendering (Leaflet), fictional rental locations, experimental radius controls, no competitor source, and a report R09 absence display. No login, real rental selection, customer data, database, scraper or backend.

## To build locally after permission is granted

Install Dart SDK and the Jaspr CLI according to current [Jaspr documentation](https://docs.jaspr.site/quick_start). From inside this extracted folder:

```powershell
dart --version
dart pub global activate jaspr_cli
dart pub get
jaspr serve
```

`lib/main.client.options.dart` is **generated by the Jaspr CLI**. Do not manually treat it as missing project data. The demo will run at the local address the CLI prints. For standalone unit tests (only after test execution is permitted):

```powershell
dart test
```

If the Jaspr CLI version in your environment uses a different app/template configuration, create a fresh **client-mode** Jaspr project with `jaspr create`, then migrate `lib/geometry_contract.dart`, `lib/main.client.dart` and the three `web/` assets into that scaffold and run the real compiler. **Do not** substitute production Project1 or teammate files during experimentation.

## What you should see

- Fictional rental A with a clearly experimental circle at 400 / 500 / 800 / 1200 m (none is adopted).
- Fictional area-only rental B, where no precise circle is drawn.
- OpenStreetMap background tiles only; **no competitor venue dataset or venue pin ingestion**.
- `SOURCE UNAVAILABLE` or `NOT QUERIED` per-candidate state, with readable report/provenance tabs.
- Explicit statement that straight-line proximity is not demand, walking time, rank, score or business suitability.

## Source and licence boundary

The demo HTML uses `https://tile.openstreetmap.org/{z}/{x}/{y}.png` for normal human map viewing with visible © OpenStreetMap contributors attribution. The map-tile service forbids bulk fetching/prefetch/offline downloads; it is not a competitor data service. See https://operations.osmfoundation.org/policies/tiles/ . Leaflet 1.9.4 is separately loaded from a public CDN for the demo; a deployed app needs reviewed dependency-pinning, integrity and availability policy.
