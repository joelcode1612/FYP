## Defects found and fixed (each one was silently wrong before)
1. **`threesixty` is not a Material Symbols ligature** — it rendered the literal word
   "threesixty" in the owner nav. Renamed to `360`, verified by measuring glyph width.
2. **Pill-nav icons had zero width** — `.app-pill__nav` flex-shrank the icon boxes to
   0px. The source's pill row is label-only; icons removed (also fixes #1's symptom).
3. **`classes: 'btn secondary'`** in FilterPanel — `secondary` alone matched no rule, so
   the reset button rendered with no variant styling.
4. **Duplicate page heads** — owner/admin dashboards rendered their own `PageHead` on
   top of `AppLayout`'s. Added `AppLayout.showPageHead` (false for the two dashboards).
5. **`SearchInput` nested a `.field` inside a `Field`** — double label + double grid gap.
6. **Empty state had an icon badge the source does not have** — `EmptyState.icon`
   removed (8 call sites), box restyled to the source's dashed border on white.
7. **Checkboxes inherited the text-input box** (`.field input { width:100%; height:40px }`)
   — the filter panel's verification pill rendered as a tall empty rectangle. Added the
   `input[type=checkbox/radio]` override that the earlier port had dropped.
8. **`.kv` three-track grid** forced values to wrap mid-word in the narrow
   `.detail-grid` right column — now flex with wrap.
9. **`.auth-submit` was `display: inline`** so width/height were ignored; `display:flex`.
10. **`.map-canvas` had no `position: relative`** — `.visual__grid` (absolute) escaped
    to the viewport and drew a grid over the entire page.
11. **Detail pages spun forever on an unknown id** — `FutureBuilder.hasData` is false
    both while pending *and* when the future completes with null. Now
    `connectionState != done` + an explicit null branch.
12. **`.rec-item` was redefined twice** (old flex column + new source grid) and
    `.btn.sm` likewise — the duplicates were removed, not merged with an alias.

## Environment gotchas worth remembering
- `jaspr build` deletes `build/jaspr` first — **stop any static server serving that
  directory** or it fails with `PathAccessException … errno 32`.
- Detail routes are pre-rendered without query params, so a browser check must wait for
  hydration (~1.5s) or it inspects the empty static shell.
- After a CSS-only change, `cp web/styles.css build/jaspr/styles.css` avoids a 3-minute
  rebuild.
